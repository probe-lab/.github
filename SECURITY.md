# Security policy

Report a security problem in a ProbeLab repository privately. Do not open a
public issue or pull request about it.

To report it, open the repository's Security tab and select "Report a
vulnerability". Describe the problem and how to reproduce it. We answer in
the report.

If the repository has no "Report a vulnerability" button, open an issue that
asks for a private contact. Do not put details of the problem in the issue.
